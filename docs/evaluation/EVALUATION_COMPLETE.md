## 🚀 How to Use the Evaluation Tools

### Step 1: Quick Check (2 minutes)
```bash
python -m scripts.evaluation.compare_with_baseline
```
- Shows if your model beats random guessing
- Quick baseline comparison

### Step 2: Speed Test (2 minutes)
```bash
python -m scripts.evaluation.benchmark_speed
```
- Measures FPS and latency
- Checks real-time capability

### Step 3: Full Comparison (10 minutes)
```bash
python -m scripts.evaluation.evaluate_model
```
- Compares against Random Forest, SVM, kNN, Decision Tree
- Generates visual charts and reports
- Saves to `results/` directory

### Step 4: Live Testing (15+ minutes)
```bash
python -m scripts.evaluation.test_gestures
```
- Test with your actual hand
- Interactive with webcam
- Collects recognition statistics
